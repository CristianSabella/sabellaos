# SabellaOS

Portfolio de **Cristian Sabella** como un escritorio gamer en 3D: hacés clic en la PC y entrás a SabellaOS, un sistema con ventanas, barra de tareas, terminal, música y todos sus proyectos.

- 3D con Three.js (la habitación está armada por código, sin modelos externos).
- JavaScript con módulos, sin frameworks.
- Funciona en PC y en celular.

Ver en vivo: https://cristiansabella.github.io/sabellaos/
